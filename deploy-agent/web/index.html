Onboard project

Creates the service compose file on the server, sets the repo's SERVICE_ENV secret, and opens a pull request that adds the deploy workflow. The PR is never auto-merged — review it, then merge. Requires the admin token.

Add service (manual — no GitHub workflow)

Manual path — only touches the server, no GitHub wiring. Use for services without a GitHub build (third-party images, manual webhook deploys, or repos the onboarding app can't reach). Prefer "Onboard project" above for new GitHub projects. Requires the admin token.
